# AssembleLink Usage

## What it does

AssembleLink helps users understand, repair, rebuild, and reproduce a workstation.

It can:

- scan installed software
- detect CPU, GPU, RAM, storage, and drivers
- classify capability groups
- generate install plans
- build approved install queues
- execute approved installs
- classify install outcomes
- stamp execution receipts

## User flow

1. Open AssembleLink.
2. Review workstation snapshot.
3. Pick a capability.
4. Review detected and recommended tools.
5. Click Install Recommended Tools.
6. Approve Windows/admin prompts.
7. AssembleLink installs approved tools.
8. AssembleLink records results and receipts.

## UX rule

Normal users should see human outcomes, not raw commands.

Advanced users may open technical details for commands, JSON, receipts, logs, and state artifacts.
