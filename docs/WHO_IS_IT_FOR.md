# Who AssembleLink Is For

## Primary users

- software developers
- game developers
- creators
- cybersecurity learners
- homelab users
- local AI users
- students
- teams rebuilding machines
- power users moving to a new PC

## Problems it solves

- What is installed?
- What can this machine build?
- What tools are missing?
- What should be installed?
- What is free versus licensed?
- What needs admin rights?
- Can this setup be rebuilt?
- Can installs be proven?
